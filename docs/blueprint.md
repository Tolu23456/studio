# **App Name**: AdBoost

## Core Features:

- User Authentication: User registration/login with email verification and password reset.
- User Dashboard: User dashboard displaying Cube balance, activity history, and referral information.
- Watch Ads: Watch-ads feature with timer and anti-cheat measures.
- Cube Wallet: Cube wallet displaying the transaction history for earning and spending cubes.
- Personalized Task Suggestions: Suggest personalized daily activities to users via a tool to optimize their earnings.
- Daily Rewards: A daily login system which rewards the user with cubes when they sign in.

## Style Guidelines:

- Primary color: A vibrant blue (#29ABE2) to represent trust and stability, essential for a platform dealing with earnings.
- Background color: Light gray (#F0F2F5) to ensure a clean and modern look, focusing user attention on the content.
- Accent color: A teal (#008080) to highlight important CTAs and interactive elements, offering a fresh contrast.
- Body and headline font: 'PT Sans' (sans-serif) for a clean, readable, and modern look across the platform.
- Simple and consistent icons from a library like FontAwesome, related to tasks, rewards, and user profiles.
- A responsive layout using a grid system, ensuring the platform is accessible and user-friendly on both desktop and mobile devices.
- Subtle transitions and loading animations to enhance user experience without being intrusive.
